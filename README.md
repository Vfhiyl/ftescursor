# ftescursor

肝胆外科 / 肝癌方向的自动化资料归档仓库。

## 目录约定

```
YYYYMM/DD/HH/
```

示例：`202607/28/17` = 2026年07月28日 17时（UTC）整理的内容。

每小时目录通常包含：

- `00_README.md` — 索引
- `01_executive_summary.md` — 执行摘要
- `02_high_evidence_papers.md` — 论文精选
- `03_guidelines_consensus.md` — 多国指南对照
- `04_news_24h.md` — 新闻
- `05_statistics_and_trials.md` — 统计与试验
- `meta.json` + `raw_*.json` — 元数据与原始检索结果
