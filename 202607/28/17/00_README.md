## 方法学说明（兼听则明）

1. **多库并行：** PubMed（PDAT/EDAT）+ Crossref created-date + Europe PMC + 多语种网页检索。  
2. **多语种：** 英 / 中 / 日 / 俄 / 法 / 德（兼韩文媒体报道）。  
3. **证据分层优先：** Cochrane 系统评价 > III 期/多中心临床与卫生经济学 > 机制与转化研究 > 新闻通稿。  
4. **指南对照：** 将中国、日本、德国、法国、俄罗斯及 BCLC 2026 更新并列，避免单一指南口径。  
5. **局限：** 严格“24 小时新发”的指南极少；故指南文件单独标注“现行权威对照”，与“窗口内新发论文/新闻”分区存放。
